## المميزات الرئيسية
- **التوليد التدريجي الاحترافي:** كتابة الرواية فصلاً فصلاً لضمان أعلى جودة سردية (نظام "العرض لا الإخبار").
- **الموازنة الديناميكية للكلمات:** نظام "التعويض الهجومي" الذي يرفع سقف الكلمات في الفصول التالية لسد أي نقص وضمان الوصول للرقم المطلوب.
- **تخصيص شامل للهوية السردية:** تحكم كامل في (النبرة، مستوى اللغة، اللهجة العربية، الجمهور، إيقاع الأحداث).
- **دعم شامل للهجات العربية:** التزام كامل بجميع اللهجات (مصرية، خليجية، شامية، مغاربية، إلخ) في السرد والحوار.
- **تدوير مفاتيح API آلياً:** دعم إضافة عدة مفاتيح Gemini للتبديل التلقائي عند انتهاء حصة الاستخدام.
##طريقة التشغيل علي الجهاز الشخصي                                                                                                                                                     تثبيت Node.js: تأكد من أن لديك Node.js (والذي يأتي معه npm) مثبتًا على جهازك. يمكنك تنزيله من الموقع الرسمي لـ Node.js.
الحصول على الكود:

قم بتنزيل ملفات المشروع أو استنساخها باستخدام Git.
تثبيت التبعيات (Dependencies):

افتح واجهة الأوامر (Terminal) في مجلد المشروع.
قم بتشغيل الأمر التالي لتثبيت جميع المكتبات التي يعتمد عليها المشروع:
npm install



تشغيل خادم التطوير:

بعد انتهاء التثبيت، قم بتشغيل الأمر التالي لبدء تشغيل التطبيق محليًا:
npm run dev



فتح التطبيق في المتصفح:

سيقوم الأمر السابق بتشغيل خادم تطوير. افتح متصفح الويب الخاص بك وانتقل إلى العنوان التالي: http://localhost:9002
الحصول على مفتاح Gemini API:

يعتمد هذا المشروع على نماذج الذكاء الاصطناعي من Google عبر Gemini. ستحتاج إلى مفتاح API خاص بك.
يمكنك الحصول على مفتاح مجاني من خلال Google AI Studio.
بمجرد تشغيل التطبيق، ستحتاج إلى إدخال هذا المفتاح في الحقل المخصص في واجهة المستخدم لبدء عملية توليد الرواية.
